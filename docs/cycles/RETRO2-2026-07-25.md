## What this run proves

1. **Fact-delivery parity ("one door") is the highest-leverage precision fix** — direct
   within-leg evidence (Math-73-c). Ship the fire-rate/screen-stats/identical facts to the
   harness-track verifier exactly as the replay track gets them.
2. **The judge-override problem is real and now 4× documented** (Math-39, Math-30×2 pre-drop,
   Closure-62). The mechanical route remains correct, but it MUST carry the trigger-input
   exemption: identical-on-both-builds firings AT the failing test's own inputs are
   patch-failed-to-fix evidence (Math-2), not pre-existing surface. Design constraint: the
   exemption must be mechanical (input/artifact comparison against the trigger corpus), and
   robust against trivially-common literals (a bare `0`/`1` match must not qualify).
3. **Boolean-swallow oracles must be rejected at screening** (Chart-26): `catch { flag=false }`
   destroys the exception identity every downstream guard needs. A static lint, same family as
   the existing self-swallow lint.
4. Judge counterexample discipline (Chart-7) is a calibration regression to watch, not yet a
   pattern (1 instance).
5. Fragile-tail recall (Math-74/104) behaves exactly as the trustworthy-recall accounting
   predicted — argument for reporting trustworthy recall as primary.
