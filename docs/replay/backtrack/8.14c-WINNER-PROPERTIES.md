## Adjudication rule, also fixed now

For each missed leg, phase 2 asks of every rule proposed in that roll: **does it
assert this same relation over this same observable, under any name?**

Verdicts allowed — three, not two, per review:

* **proposed** — a rule asserting the same relation over the same observable exists
* **not-proposed** — no proposed rule asserts it
* **ambiguous** — a proposed rule is adjacent (same observable, weaker/different
  relation; or same relation over a related observable) and the call is a judgment
  I do not trust either way

An honest **ambiguous** count is itself the finding: if several legs land there,
the gate cannot be resolved by archival reading at all, and the invention items
need a live A/B rather than an archive read.
