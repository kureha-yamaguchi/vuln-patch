# 8.15 — Authority-tier and authority-scope study: DOES NOT SEPARATE

Population: every KEPT verdict (`VERDICT: SOUND`) in the final30 pair —
**24 on false-accusation legs, 67 on genuine-catch legs**. Read against *both*
populations, per the guard rule.

Tested both dimensions, because 8.6 showed tier alone would mis-score Math-39
(its accusation invokes tier 1 and is entitled to; what fails is scope).

## Dimension 1 — which authority is invoked

| authority tier | false-accusation | genuine-catch |
|---|---|---|
| 4 · model memory / unattributed | 58% | 60% |
| 3 · documentation | 29% | 28% |
| 1 · failing-test pins | 12% | 12% |
| 2 · buggy build | 0% | 0% |

**Identical distributions.** Within a couple of points on every tier.

Grounded citations: **0 of 24** false-accusation, 5 of 67 genuine-catch (7%).
Directionally right, far too thin to gate on, and consistent with 2b's finding
that accusations are ~90% uncited by design.

## Dimension 2 — does the invoked authority reach this firing (scope)

| scope signal | false-accusation | genuine-catch | separates? |
|---|---|---|---|
| fires at the test's OWN input literals | 33% | 40% | no |
| the real failing test PASSES here | 8% | 1% | no (2 rows vs 1) |
| replay-confirmed on the patched build | 50% | 63% | no |
| buggy-replay fact present | 100% | 100% | no |

**Nothing separates.** The largest gap is 13 points on replay-confirmation, in a
24-vs-67 sample, and it runs the *wrong* way for a precision gate (genuine catches
are *more* replay-confirmed, so gating on it would void catches first).

The one signal pointing the right way — "the real test passes here", which is
exactly Math-39's shape — is **2 rows against 1**. That is not a measurement.

## Verdict: closed, same standard as the separating-fact study

Neither authority tier nor authority scope distinguishes a kept genuine catch from
a kept false accusation. **No computed authority-tier fact is licensed.**

The guard question is moot rather than passed: since nothing separates, there is
no candidate tier to test against the 67-row guard set. Nothing to void because
nothing to gate.

## What this adds to the ceiling picture

The cycle-7 separating study tested *delivery-side* features — corroboration
count, firing location, fire-rate presence, replay confirmation — and found no
separation. It explicitly left open that it "never tested WHICH AUTHORITY the
checked property derives from".

**That gap is now closed, and closed negatively.** Authority — the dimension the
trust hierarchy is built on, and the one the meta-rule says exists today only as
prompt guidance — is measured not to separate either, on either the tier or the
scope reading.

So the ceiling evidence now covers: delivery features (cycle 7), narrow structured
questioning (the engagement experiment), and authority (this). Three independent
dimensions, three negatives.

## Honest limit

Both dimensions were classified by keyword over the check's rationale and the
judge's WHY. That is crude for tier and cruder for scope — "the real test passes
here" is the only scope signal recorded mechanically, and it fires on 3 rows
total. A richer scope measure would need the firing input compared against the
test's pinned scenario, which is 8.3's buggy-value territory and does not exist
yet.

So this closes the question *as askable from the current record*. It does not
prove no scope signal exists — it proves none is extractable from what we record.
